\# Portal de Consulta de Créditos Vehiculares



Prototipo funcional de aplicación web para que los clientes consulten la información de sus créditos vehiculares.

Proyecto de prácticas universitarias – Ingeniería de Software.



> \*\*Aviso:\*\* este prototipo funciona exclusivamente con \*\*datos ficticios\*\*. No está conectado a ningún sistema

> de la empresa ni procesa pagos reales. Una integración futura requeriría autorización expresa de la empresa

> y un proveedor de pagos autorizado.



\## Tecnologías

\- \*\*Frontend:\*\* Angular

\- \*\*Backend:\*\* Java 17 + Spring Boot (API REST)

\- \*\*Base de datos:\*\* MySQL 8.4 LTS



\## Estructura del repositorio

| Carpeta | Contenido |

|---|---|

| `backend/` | API REST en Spring Boot |

| `frontend/` | Aplicación Angular |

| `database/` | Scripts SQL y datos ficticios |

| `plantillas-importacion/` | Plantillas Excel/CSV de ejemplo |

| `docs/` | Documentación, diagramas y evidencias de pruebas |
